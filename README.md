# Digital Marketing Education Website (Next.js + React)

ဒီ project က Digital Marketing သင်ကြားရေး website template ဖြစ်ပါတယ်။

## Run လုပ်ရန်

```bash
npm install
npm run dev
```

ပြီးရင် browser မှာ `http://localhost:3000` ဖွင့်ပါ။

## ပါဝင်တဲ့ sections

- Video lesson player
- Lesson locking system
- Video completion tracking
- Quiz answer tracking
- Tools section
- Footer

Lesson တစ်ခုမှာ video ကိုအဆုံးထိမကြည့်သေးတာ၊ quiz မဖြေသေးတာရှိရင် နောက် lesson video ကို lock လုပ်ထားပါတယ်။

## Tech stack

- Next.js (App Router)
- React
- CSS (global stylesheet)
